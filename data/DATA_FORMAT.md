# 問題データの形式（data/questions.js）

アプリは `data/questions.js` だけを問題データとして読み込みます。
Codex が作った本番データに差し替えるときは、**このファイルを丸ごと置き換える**だけで済みます（画面のコードは触りません）。

ファイルの形は次のとおりです。先頭の `window.LISTENING_DATA =` と末尾の `;` は変えないでください。

```js
window.LISTENING_DATA = {
  "schemaVersion": 1,
  "weekLabel": "2026年11月 第3週",     // ホーム画面に表示（省略可）
  "days": [ /* 月〜金の5日分 */ ]
};
```

## 構成ルール

| 項目 | ルール |
|---|---|
| 日 | `mon` `tue` `wed` `thu` `fri` の5日分（各1回ずつ） |
| 1日の大問 | 3つ（`sections` の順に大問1・2・3） |
| 問題数 | 大問1＝3問、大問2＝2問、大問3＝2問（計7問） |
| 選択肢 | 必ず4つ（A〜D）。`answer` は 0〜3 の番号（0=A, 1=B, 2=C, 3=D） |
| 画面の文章 | `ja`（日本語訳）・`explanation`（解説）は日本語、それ以外は英語 |

## 1日分

```json
{
  "day": "mon",
  "isDummy": false,
  "sections": [ /* 大問1, 大問2, 大問3 */ ]
}
```

- `isDummy`：仮データのときだけ `true`（画面に「仮データ」と出ます）。本番データでは書かないか `false`。
- `note`：任意のメモ（画面には出ません）。

## 大問

```json
{
  "id": "mon-1",
  "number": 1,
  "type": "word",
  "title": "単語を選ぶ",
  "instruction": "短い英文を聞いて、内容に合う英単語を選びましょう。",
  "questions": [ /* 問題 */ ]
}
```

- `type`：`word`（大問1）／`conversation`（大問2）／`talk`（大問3）。
- `title` と `instruction` は省略可（省略すると標準の文言が出ます）。

## 問題

```json
{
  "id": "mon-2-1",
  "lines": [
    { "speaker": "Woman", "gender": "female", "text": "英文", "ja": "日本語訳" },
    { "speaker": "Man",   "gender": "male",   "text": "英文", "ja": "日本語訳" }
  ],
  "question": { "text": "質問の英文", "ja": "質問の日本語訳" },
  "choices": [
    { "text": "選択肢A（英語）", "ja": "日本語訳" },
    { "text": "選択肢B（英語）", "ja": "日本語訳" },
    { "text": "選択肢C（英語）", "ja": "日本語訳" },
    { "text": "選択肢D（英語）", "ja": "日本語訳" }
  ],
  "answer": 1,
  "explanation": "日本語の解説"
}
```

- `id`：全問題で重複しない文字列（例：`mon-2-1`）。
- `lines`：読み上げる順に並べます。1行＝1人の発話のまとまりです。
  - `speaker`：話者の名前（画面の英文表示に出ます）。**同じ人は同じ名前**、別人は別の名前にします（例：`Woman 1` / `Woman 2`）。名前ごとに声が割り当てられます。
  - `gender`：`female` か `male`。声の男女を決めます。
  - 長い独話（案内・説明）は、1人の話者のまま複数の `lines` に分けても構いません。
- `question`：大問2・3では必須。大問1では書きません（英文を聞いて単語を選ぶだけ）。質問は音声の最後に別の声で読まれます。
- `choices`：選択肢は大問1が英単語、大問2・3が英語の1文。
- 日本語訳（`ja`）は「答えを見る」を押すまで表示されません。

## 差し替え後の確認

`index.html` を開き、月〜金のすべてが選べて、7問ずつ表示されることを確認します。
形式に問題があると、画面にエラー内容が日本語で表示されます。
